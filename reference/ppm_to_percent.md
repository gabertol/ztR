# Convert PPM to Percentage

This function converts a value from parts per million (PPM) to a
percentage.

## Usage

``` r
ppm_to_percent(ppm_value)
```

## Arguments

- ppm_value:

  Numeric value representing the concentration in parts per million.

## Value

A numeric value representing the concentration in percentage.

## Examples

``` r
ppm_to_percent(10000) # returns 1
#> [1] 1
ppm_to_percent(5000)  # returns 0.5
#> [1] 0.5
```
