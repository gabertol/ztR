# Calculate the Fraction of Ti on the Si-Site in Zircon

This function calculates the fraction of titanium (Ti) on the Si-site in
zircon as a function of pressure.

## Usage

``` r
zircon_ti_f_site(P)
```

## Arguments

- P:

  Numeric. Pressure in gigapascals (GPa).

## Value

Numeric. The fraction of Ti on the Si-site in zircon.

## Examples

``` r
# Example usage:
zircon_ti_f_site(1.5)
#> [1] 0.9939416

```
